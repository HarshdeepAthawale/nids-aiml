# Network Intrusion Detection System
### UNSW-NB15 · Random Forest · FastAPI · ML Course Project

A complete binary classifier that detects network attacks vs. normal traffic using the [UNSW-NB15 dataset](https://www.kaggle.com/datasets/mrwellsdavid/unsw-nb15).

---

## Quick Start

### 1. Install dependencies
```bash
pip install -r requirements.txt
```

### 2. Get the dataset (optional — synthetic data works without it)
```bash
# Option A: Kaggle CLI (requires ~/.kaggle/kaggle.json)
python data/download_data.py

# Option B: Manual download
# Go to https://www.kaggle.com/datasets/mrwellsdavid/unsw-nb15
# Download and place UNSW_NB15_training-set.csv + UNSW_NB15_testing-set.csv in data/
```

### 3. Train the model
```bash
python scripts/train.py
# Uses synthetic data if real CSVs aren't present (good for testing the pipeline)
```

### 4. Start the backend API
```bash
uvicorn backend.app:app --reload
# → http://localhost:8000
# → http://localhost:8000/docs  (Swagger UI)
```

### 5. Open the frontend
Open `frontend/index.html` in your browser.  
Click **Sample: Normal** or **Sample: Attack**, then **Analyze Flow**.

## API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/health` | Liveness check |
| POST | `/predict` | Classify one network flow |
| GET | `/sample/normal` | Example normal-traffic payload |
| GET | `/sample/attack` | Example attack-traffic payload |
| GET | `/docs` | Swagger UI |

## Model Performance (real UNSW-NB15 data)

| Model | Accuracy | F1-Score |
|-------|----------|----------|
| Logistic Regression | ~89.8% | ~0.93 |
| **Random Forest** | **~95.0%** | **~0.96** |

## Attack Categories in Dataset
Generic · Exploits · Fuzzers · DoS · Reconnaissance · Analysis · Backdoor · Shellcode · Worms

## Tech Stack
- **ML:** scikit-learn (Random Forest, Logistic Regression, StandardScaler, VarianceThreshold)
- **API:** FastAPI + Uvicorn
- **Frontend:** Vanilla HTML/CSS/JS (zero dependencies, single file)
- **Data:** pandas + numpy
